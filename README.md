# 📊 India CPI Inflation Trend Analysis (Microsoft Excel)

## 📌 Project Overview
This repository contains an analytical project using **Microsoft Excel** to evaluate India's **Consumer Price Index (CPI)** and historical inflation trends. The study explores dynamic inflation patterns across various commodity categories to provide data-driven insights.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel** (Data Cleaning, Pivot Tables, Moving Averages, XLOOKUP/VLOOKUP)
* **Data Visualization** (Dynamic Charts, Line Graphs, Trend Analysis Dashboards)

---

## 🔍 Problem Statements Addressed
1. **Trend Identification**: Evaluating the overall inflation trajectory and identifying key spikes over historical periods.
2. **Category Comparison**: Analyzing how specific commodity groups (e.g., food, fuel) contribute differently to the Composite CPI.
3. **Data Aggregation**: Utilizing Pivot tables to summarize and categorize complex inflation datasets.
4. **Inflation Modeling**: Applying moving averages and lookup functions to smooth data and track temporal consistency.
5. **Insights Visualization**: Building dynamic charts to translate complex economic data into easily digestible visual narratives.
